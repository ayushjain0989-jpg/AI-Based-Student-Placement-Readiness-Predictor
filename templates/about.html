About PlacementAI

AI-Based Student Placement Readiness Predictor

What is PlacementAI?

PlacementAI is an AI-based student placement readiness prediction system designed to help students understand their preparedness for campus placement opportunities.

The system analyzes various academic and skill-related factors and uses Machine Learning models to predict a student's placement readiness.

How It Works

1

Student Assessment

Students provide their academic, internship, training, project and communication information.

2

AI Prediction

Machine Learning models analyze the submitted information and predict placement probability.

3

Skill Gap Analysis

The system identifies areas where the student can improve.

4

Personalized Recommendations

Students receive recommendations to improve their placement readiness.

Technologies Used

Python Programming Language
Flask Web Framework
CatBoost Machine Learning
XGBoost Machine Learning
Random Forest Machine Learning
SHAP Explainable AI
SQLite Database

Project Objective

The main objective of PlacementAI is to provide students with an intelligent and easy-to-understand assessment of their placement preparedness.

Instead of providing only a prediction, the system also explains important factors influencing the prediction and provides actionable recommendations for improvement.
